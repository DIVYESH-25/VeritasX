# VeritasX — AI Image Detection System

VeritasX is an AI Generated Image Detection System designed to help users verify whether images are synthetic (AI-generated) or real with high-precision deep learning forensics.

## 📂 Project Structure

```
VeritasX/
├── README.md                 # Project Overview & Setup Instructions
├── .gitignore                # Git Ignore Rules
└── frontend/                 # Frontend Web Application (React + Vite + TypeScript)
    ├── src/                  # React Source Components & 3D Shaders
    ├── index.html            # Entry HTML Document
    ├── package.json          # Dependencies & Build Scripts
    ├── tailwind.config.js    # Cyber Design System Theme Tokens
    ├── tsconfig.json         # TypeScript Config
    └── vite.config.ts        # Vite Bundler Config
```

## 🚀 Features

- **Futuristic AI Security Interface**: Dark theme (`#020617`), signature cyan glow (`#00E5FF`), 20% transparent glass black panels, and smooth Lenis scrolling.
- **Full-Screen 3D Cyan Cosmic Starfield**: Interactive Three.js / React Three Fiber space background reacting smoothly to cursor movement.
- **Custom Cyber Reticle Cursor**: Real-time canvas particle trails and custom signature cyan click particle explosions.
- **5-Image Upload & Detection Workspace**: Drag and drop up to 5 local images simultaneously with synchronized laser scanning animations and synthetic probability gauges.

## 📦 Getting Started

### Installation & Local Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/veritas-x.git
   cd veritas-x/frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
